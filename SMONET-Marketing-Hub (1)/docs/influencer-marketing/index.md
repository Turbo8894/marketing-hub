# 红人营销总览

标准流程：红人筛选 → 个性化开发 → 报价评估 → 商务谈判 → 内部审批 → 寄样 → 内容跟进 → 草稿审核 → 发布与付款 → 数据复盘。

## 核心记录字段

| 类型 | 字段 |
| --- | --- |
| 身份 | 姓名、平台、主页、邮箱、地区 |
| 数据 | 粉丝、平均播放、互动、受众地区 |
| 商务 | 初始报价、最终价格、交付内容、付款方式 |
| 执行 | 产品、寄送状态、预计交稿、当前进度 |
| 结果 | 链接、播放、点击、订单、内容质量、复投建议 |
