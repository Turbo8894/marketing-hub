# 商务谈判 SOP

## 谈判顺序

1. 感谢对方并认可内容价值。
2. 确认报价对应的交付内容、平台和使用权。
3. 说明当前属于首次测试合作及预算限制。
4. 提出明确、可执行的预算方案。
5. 用产品价值、佣金、跨平台发布或长期合作补充价值。
6. 对方不能接受时，保留未来合作空间。

## 评估维度

- 预计触达与内容质量
- 平台组合及是否重复发布
- 是否包含原始素材、使用权或广告授权
- 产品成本、现金预算和佣金
- 创作者过往同类产品表现
- 首次测试的风险和未来复投可能

:::warning
不要用虚假长期合作承诺施压，也不要把“产品价值”直接等同于现金报酬。
:::
