# 渠道筛选与评估

| 维度 | 重点问题 |
| --- | --- |
| 受众 | 是否以美国消费者、家庭用户和 Amazon 买家为主？ |
| 活跃 | 近期帖子是否有真实评论、点击或抢购反馈？ |
| 规则 | 谁可以发帖？是否允许外链、折扣码和置顶？ |
| 商务 | 单次价格、套餐、有效期和补发政策是什么？ |
| 数据 | 能否提供发布链接，并通过独立链接追踪结果？ |
| 风险 | 是否存在虚假成员、重复群组或短时间删帖？ |

## 优先级

- A 级：历史有订单、点击质量稳定，可持续复投。
- B 级：点击尚可但订单不稳定，继续小额测试。
- C 级：低点击、低订单或配合差，停止投入。
