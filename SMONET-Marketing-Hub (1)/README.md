# SMONET Marketing Hub

SMONET 海外 KOL 与 Deal 推广团队知识库，基于 Docusaurus 构建。

## 本地使用

```bash
yarn install
yarn start
```

生产构建：

```bash
yarn build
```

## 内容目录

- `docs/products`：产品资料
- `docs/influencer-marketing`：红人营销 SOP
- `docs/deal-marketing`：Deal 推广
- `docs/templates`：邮件与反馈模板
- `docs/operations`：运营流程
- `docs/case-studies`：案例复盘

新增文章时，在对应目录中创建 Markdown 文件，并通过页面顶部的 `sidebar_position` 控制顺序。
